# Requisitos do produto

## Problema

Candidatos frequentemente possuem experiências relevantes, mas têm dificuldade para adaptar seus currículos a diferentes vagas sem exagerar ou inventar competências.

## Solução

O Evidentia AI permitirá que o usuário escreva suas experiências ou envie documentos. A aplicação recuperará as evidências mais relevantes para uma vaga e ajudará a gerar um currículo adaptado.

## Entradas

- Experiências escritas manualmente.
- Projetos escritos manualmente.
- Cursos e certificações.
- Currículos antigos.
- Portfólios.
- Descrições de projetos.
- Descrição da vaga desejada.

## Saídas

- Competências encontradas.
- Competências não encontradas.
- Evidências relacionadas a cada competência.
- Sugestões de melhoria.
- Resumo profissional adaptado.
- Experiências profissionais adaptadas.
- Currículo editável.

## Regras importantes

1. O sistema não deve inventar experiências.
2. O sistema não deve adicionar uma competência sem evidência fornecida pelo usuário.
3. Toda sugestão deve poder ser relacionada a uma fonte.
4. O usuário deve poder revisar e editar o texto gerado.
5. O sistema deve informar quando não encontrar evidências suficientes.
6. Documentos reais não devem ser versionados no Git.
